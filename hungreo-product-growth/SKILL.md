# Hungreo Product Growth

Giữ đúng vibe của Hưng: **simple, safe, effective** + luôn hỏi “real problem” trước.

## Quick start (khi Hưng quăng 1 yêu cầu)

1. Xác nhận mục tiêu (ai đọc? làm gì? metric nào?)
2. Chọn format output (App Store / landing / onboarding / paywall / release note / UAT synthesis)
3. Viết bản nháp → 1 vòng chỉnh theo tone **chân thành + hài hước nhẹ**.

## Outputs chuẩn (VN)

### 1) App Store listing (VN)

- Title (<=30 ký tự)
- Subtitle (<=30 ký tự)
- Mô tả dài (đoạn ngắn, dễ đọc)
- “What’s New” (3–6 bullet)

Template: xem `references/appstore-vn.md`.

### 2) Onboarding + Paywall copy (subscription)

- 1 câu value proposition (rõ lợi ích)
- 3 bullet lợi ích (đo được)
- Chốt CTA (đơn giản)

Template: xem `references/onboarding-paywall-vn.md`.

### 3) UAT feedback synthesis (để ra quyết định)

- Gom feedback → nhóm (Bug / UX / Missing feature / Pricing / Copy)
- Ưu tiên theo Impact x Frequency x Confidence
- Kết luận: 3 việc làm ngay, 3 việc để sau

Template: xem `references/uat-synthesis.md`.

### 4) Experiment ideas (VN-first)

- Hypothesis → Metric → Minimal change → Risks

Template: xem `references/experiments.md`.
