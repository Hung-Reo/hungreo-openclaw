# Release checklist (mobile app)

## Trước khi release

- [ ] Crash-free / basic smoke test
- [ ] Paywall: purchase/restore/cancel flow OK
- [ ] Analytics events chính bắn đúng
- [ ] Privacy: permissions + policy text đúng
- [ ] App Store/CH Play metadata cập nhật
- [ ] Release notes (VN)

## Sau khi release

- [ ] Monitor crash + review key user feedback
- [ ] Check subscription conversion + refund anomalies
